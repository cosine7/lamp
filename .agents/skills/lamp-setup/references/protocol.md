# 协议与手动配置

## 来源与验证

算法改编自 [NicoIIT/ha-ble-adv 的 AgarceRemoteEncoder](https://github.com/NicoIIT/ha-ble-adv/blob/main/custom_components/ble_adv/codecs/agarce.py)，采用 MIT 授权，原文保存在项目的 `THIRD-PARTY-LICENSE.txt`。

本项目协议名为 `argrace_remote_v4`，已验证的厂商 ID 为 `0x09F9`、遥控器前缀为 `04`。灯转发的广播可能以 `03` 开头；学习流程采集前缀 `04` 的原遥控器开关指令。

## 数据格式

厂商数据共 22 字节：

| 部分 | 长度 |
| --- | --- |
| 前缀 | 1 字节 |
| 随机种子 | 4 字节 |
| 白化负载及内部校验 | 16 字节 |
| 外部校验 | 1 字节 |

解码时验证两个校验值。保存的模板共 20 字节，包含前缀、种子和解码后的 15 字节负载，省略两个校验字节。

| 模板位置（从 0 开始） | 含义 |
| --- | --- |
| 0 | 前缀 04 |
| 1–4 | 随机种子 |
| 5 | 发送计数 |
| 6 | 重启计数 |
| 9–14 | 六字节遥控器 ID，按数据包字节顺序 |
| 16 | 命令：01 开灯，02 关灯 |
| 17 | 当前实现使用的按键计数 |
| 18–19 | 沿用采集模板的参数，含义待确认 |

## 手动配置

`lamp learn` 会把原始广播解码成模板。手动设置使用解码后的 20 字节十六进制模板：

```text
lamp config set --on-template <on-template> --off-template <off-template>
```

执行时将占位符替换为实际值并去掉尖括号。完整模板提供遥控器 ID、命令及其他参数。

`lamp config set --id <remote-id>` 修改已有模板的第 9～14 字节。`<remote-id>` 是六字节十六进制 ID，按模板里的字节顺序填写。蓝牙显示地址需要先确认与模板 ID 的对应关系。

完整 JSON 配置使用 `lamp config import <file>` 导入，`<file>` 为文件路径。

## 计数与备份

实灯测试中，更新随机种子和计数后能够控制灯。当前实现先在磁盘保存新计数，再发送广播，停止和重启后继续使用保存的状态。

`state.json` 由服务维护。手动迁移或恢复前，先停止使用这套数据的服务。配置导出只包含用户配置，发送计数需另外备份。对同一配置的发送由一个服务串行处理。
